# Dux Mini GPT
Нөлден үйретілетін кішкентай GPT (~11 млн параметр, байт деңгейі: кез келген тіл мен код).
Ол мәтінді жалғастырады, сұраққа жауап беретін чат емес. Чат үшін диалог деректері керек.

Colab: `dux_mini_gpt.ipynb` ашыңыз → T4 GPU → ұяшықтарды іске қосыңыз.
Локально: `python train.py train data.txt 3000`, содан кейін `python train.py gen "Сәлем"`.
